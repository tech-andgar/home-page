Cambiar entre múltiples cuentas de Claude Code (Bedrock SSO + Claude.ai Team)

marzo 24, 2026 3 minutos de lectura.
Devtools • Ai
Claude-Code • Aws-Bedrock • SSO • Developer-Tools

Problema Link to heading

Claude Code almacena su proveedor de autenticación en ~/.claude/settings.json. Si tu máquina está configurada para AWS Bedrock SSO (por ejemplo, una configuración corporativa), esto sobreescribe todo — incluyendo variables de entorno del shell y configuraciones del workspace de VSCode. Cerrar sesión y volver a iniciarla no ayuda porque Bedrock se reconecta automáticamente usando las credenciales de AWS.

Causa raíz Link to heading

~/.claude/settings.json tiene un bloque env que inyecta variables de entorno a nivel del proceso de Claude, antes de que el shell pueda sobreescribirlas:

  "env": {
    "CLAUDE_CODE_USE_BEDROCK": "1",
    "ANTHROPIC_MODEL": "global.anthropic.claude-sonnet-4-6",
    ...
  }
}

Esta configuración es establecida por IT corporativo y no puede ser sobreescrita con aliases del shell ni con configuraciones del workspace de VSCode.

Solución: Funciones de shell que modifican settings.json Link to heading

Renombra las funciones según tu contexto (ej. claude-empresa / claude-cliente). Agrega esto a ~/.zshrc:

# Toggle de cuenta Claude
export CLAUDE_CODE_USE_BEDROCK=0  # por defecto: sin Bedrock

# Cambiar a AWS Bedrock (ej. cuenta SSO del empleador)
claude-company() {
  python3 -c "
import json
with open('$HOME/.claude/settings.json', 'r') as f: d = json.load(f)
d.setdefault('env', {}).update({
  'CLAUDE_CODE_USE_BEDROCK': '1',
  'ANTHROPIC_MODEL': 'global.anthropic.claude-sonnet-4-6',
  'ANTHROPIC_DEFAULT_HAIKU_MODEL': 'global.anthropic.claude-haiku-4-5-20251001-v1:0',
  'ANTHROPIC_DEFAULT_SONNET_MODEL': 'global.anthropic.claude-sonnet-4-6',
  'ANTHROPIC_DEFAULT_OPUS_MODEL': 'global.anthropic.claude-opus-4-6-v1',
  'CLAUDE_CODE_SUBAGENT_MODEL': 'global.anthropic.claude-haiku-4-5-20251001-v1:0',
  'AWS_REGION': 'us-east-1',       # ajusta tu región
  'AWS_PROFILE': 'default'          # ajusta tu perfil de AWS
})
with open('$HOME/.claude/settings.json', 'w') as f: json.dump(d, f, indent=2)
"
  claude auth logout 2>/dev/null
  echo "→ AWS Bedrock (empresa)"
}

# Cambiar a Claude.ai Team (ej. cuenta del cliente)
claude-client() {
  python3 -c "
import json
with open('$HOME/.claude/settings.json', 'r') as f: d = json.load(f)
for k in ['CLAUDE_CODE_USE_BEDROCK','ANTHROPIC_MODEL','ANTHROPIC_DEFAULT_HAIKU_MODEL','ANTHROPIC_DEFAULT_SONNET_MODEL','ANTHROPIC_DEFAULT_OPUS_MODEL','CLAUDE_CODE_SUBAGENT_MODEL','AWS_REGION','AWS_PROFILE']:
  d['env'].pop(k, None)
with open('$HOME/.claude/settings.json', 'w') as f: json.dump(d, f, indent=2)
"
  claude auth logout 2>/dev/null
  echo "→ Claude.ai Team (cliente)"
  claude auth login
}

Recarga: source ~/.zshrc

Uso Link to heading

1
2
3

claude-company     # Cambiar a AWS Bedrock SSO (empresa)
claude-client      # Cambiar a Claude.ai Team (abre login en el navegador)
claude auth status # Verificar la cuenta activa

Resultado esperado de claude auth status:

Bedrock:

1

{ "authMethod": "third_party", "apiProvider": "bedrock" }

Claude.ai Team:

1
